# Hand Image Annotation Project
## Overview 
This project demonstrates the use of basic computer image annotation completed in CVAT.

I annotated 52 images using bounding boxes and labeled each hand as 'left_hand' or 'right_hand'

## Tools Used
- CVAT
- GitHub
- XML annotation export

## Annotation Details 
- Total images: 52
- Annotation Type: Bounding Boxes
- Labels: 'left_hand' and 'right_hand'

## Quality Review 
I reviewed the annotations for:
- Incorrect labels
- Duplicates of bounding boxes
- Consistency

## Repository Contents 
- 'annotations.xml' = completed project
